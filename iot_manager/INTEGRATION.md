# IoT Device Management Integration Guide

## Overview

This guide explains how to integrate the IoT device management system with the existing FreeBSD router configuration.

## Integration Steps

### 1. Update Router Configuration

#### A. Dynamic VLAN Creation Script

Create a script to dynamically manage VLANs based on device database:

**File**: `/usr/local/sbin/update_vlans.sh`

```bash
#!/bin/sh
# Update VLAN interfaces based on IoT manager database

IOT_DB_PATH="/mnt/network_storage/iot_manager/devices.json"

# Check if database exists
if [ ! -f "$IOT_DB_PATH" ]; then
    echo "Device database not found: $IOT_DB_PATH"
    exit 1
fi

# Parse JSON and create VLAN interfaces
python3 << 'PYTHON_SCRIPT'
import json
import sys
import subprocess

try:
    with open('/mnt/network_storage/iot_manager/devices.json', 'r') as f:
        data = json.load(f)
    
    devices = data.get('devices', {})
    
    for mac, device_info in devices.items():
        vlan_id = device_info.get('vlan_id')
        if vlan_id and not device_info.get('quarantined'):
            # Create VLAN interface if it doesn't exist
            result = subprocess.run(['ifconfig', f'vlan{vlan_id}'], 
                                  capture_output=True)
            if result.returncode != 0:
                # VLAN doesn't exist, create it
                subnet = f"192.168.{vlan_id}.1/24"
                print(f"Creating VLAN {vlan_id} for {device_info.get('name')}")
                subprocess.run([
                    'ifconfig', f'vlan{vlan_id}', 'create',
                    'vlan', str(vlan_id), 'vlandev', 'em1',
                    'inet', subnet, 'up'
                ])

except Exception as e:
    print(f"Error: {e}", file=sys.stderr)
    sys.exit(1)
PYTHON_SCRIPT
```

#### C. Dynamic Firewall Rules

**File**: `/usr/local/sbin/update_iot_firewall.sh`

```bash
#!/bin/sh
# Generate pf firewall rules for IoT devices

IOT_DB_PATH="/mnt/network_storage/iot_manager/devices.json"
PF_IOT_RULES="/etc/pf.iot.conf"

python3 << 'PYTHON_SCRIPT'
import json

try:
    with open('/mnt/network_storage/iot_manager/devices.json', 'r') as f:
        data = json.load(f)
    
    devices = data.get('devices', {})
    
    with open('/etc/pf.iot.conf', 'w') as pf_file:
        pf_file.write("# Auto-generated IoT device firewall rules\n")
        pf_file.write("# DO NOT EDIT MANUALLY - Generated by IoT Manager\n\n")
        
        # NAT rules
        pf_file.write("# NAT rules for IoT VLANs\n")
        for mac, device_info in devices.items():
            vlan_id = device_info.get('vlan_id')
            if vlan_id and not device_info.get('quarantined'):
                pf_file.write(f"nat on $wan_if from 192.168.{vlan_id}.0/24 to any -> ($wan_if)\n")
        
        pf_file.write("\n# Firewall rules for IoT devices\n")
        for mac, device_info in devices.items():
            vlan_id = device_info.get('vlan_id')
            device_name = device_info.get('name', 'Unknown')
            
            if vlan_id and not device_info.get('quarantined'):
                pf_file.write(f"\n# {device_name} (VLAN {vlan_id})\n")
                pf_file.write(f"pass in on vlan{vlan_id} proto icmp\n")
                pf_file.write(f"pass in on vlan{vlan_id} proto udp from any to any port 53\n")
                pf_file.write(f"pass in on vlan{vlan_id} proto tcp from any to any port 443\n")
                
                # Add device-specific ports from profile
                if 'required_ports' in device_info:
                    for port in device_info['required_ports']:
                        pf_file.write(f"pass in on vlan{vlan_id} proto {{ tcp udp }} to port {port}\n")
                
                # Block everything else
                pf_file.write(f"block in on vlan{vlan_id} all\n")
        
        # Quarantine VLAN rules
        pf_file.write("\n# Quarantine VLAN (VLAN 255)\n")
        pf_file.write("pass in on vlan255 proto icmp\n")
        pf_file.write("block in on vlan255 all\n")

except Exception as e:
    print(f"Error: {e}", file=sys.stderr)
    sys.exit(1)
PYTHON_SCRIPT

# Reload firewall
pfctl -f /etc/pf.conf
```

### 3. Automated Device Detection

#### A. Create Detection Service

**File**: `/usr/local/etc/rc.d/iot_detect`

```bash
#!/bin/sh

# PROVIDE: iot_detect
# REQUIRE: NETWORKING
# KEYWORD: shutdown

. /etc/rc.subr

name="iot_detect"
rcvar="iot_detect_enable"
command="/usr/local/bin/python3"
command_args="/usr/local/sbin/iot_detect_daemon.py"
pidfile="/var/run/${name}.pid"

load_rc_config $name
run_rc_command "$1"
```

**File**: `/usr/local/sbin/iot_detect_daemon.py`

```python
#!/usr/bin/env python3
"""
IoT Device Detection Daemon
Periodically scans for new devices and updates database
"""

import sys
import time
import os

sys.path.insert(0, '/home/julian/homelab/bsd_router_test')

from iot_manager.device_database import DeviceDatabase
from iot_manager.device_profiles import DeviceProfileDatabase
from iot_manager.detection import DeviceDetector
from iot_manager.alerts import AlertManager, AlertType, AlertLevel

DB_PATH = os.environ.get('IOT_DB_PATH', '/mnt/network_storage/iot_manager/devices.json')
ALERTS_PATH = os.environ.get('IOT_ALERTS_PATH', '/mnt/network_storage/iot_manager/alerts.json')
PROFILES_DIR = os.environ.get('IOT_PROFILES_DIR', '/mnt/network_storage/iot_manager/profiles')
SCAN_INTERVAL = 300  # 5 minutes

def main():
    """Main daemon loop"""
    device_db = DeviceDatabase(DB_PATH)
    profile_db = DeviceProfileDatabase(PROFILES_DIR)
    detector = DeviceDetector()
    alert_mgr = AlertManager(ALERTS_PATH)
    
    print(f"IoT Detection Daemon started")
    print(f"Database: {DB_PATH}")
    print(f"Scan interval: {SCAN_INTERVAL} seconds")
    
    while True:
        try:
            # Detect devices
            devices = detector.detect_devices()
            
            # Check for new IoT devices
            for device in devices:
                mac = device['mac_address']
                existing = device_db.get_device(mac)
                
                if not existing:
                    # Check if it's an IoT device
                    is_iot, confidence = detector.is_iot_device(device)
                    
                    if is_iot and confidence >= 0.6:
                        # Match to profile
                        profile = profile_db.match_device(
                            mac,
                            device.get('hostname'),
                            device.get('dhcp_fingerprint')
                        )
                        
                        device_info = {
                            'name': device.get('hostname', f"Device-{mac[-8:]}"),
                            'detected_timestamp': device['detected_timestamp'],
                            'manufacturer': device.get('manufacturer', 'Unknown'),
                            'ip_address': device.get('ip_address'),
                        }
                        
                        if profile:
                            device_info['profile_name'] = profile.name
                            device_info['model'] = profile.model
                            device_info['category'] = profile.category
                        
                        vlan = device_db.add_device(mac, device_info)
                        
                        # Create alert for new device
                        alert_mgr.create_alert(
                            AlertType.DEVICE_BEHAVIOR,
                            AlertLevel.INFO,
                            f"New IoT device detected: {device_info['name']}",
                            mac,
                            {'vlan_id': vlan, 'confidence': confidence}
                        )
                        
                        print(f"Added new device: {mac} to VLAN {vlan}")
            
        except Exception as e:
            print(f"Error in detection loop: {e}")
        
        time.sleep(SCAN_INTERVAL)

if __name__ == '__main__':
    main()
```

```bash

# Start service
```

### 4. Resource Monitoring

#### A. Create Monitoring Script

**File**: `/usr/local/sbin/iot_monitor.sh`

```bash
#!/bin/sh
# Resource monitoring for IoT manager

/usr/local/bin/python3 << 'PYTHON_SCRIPT'
import sys
import os

sys.path.insert(0, '/home/julian/homelab/bsd_router_test')

from iot_manager.monitoring import ResourceMonitor
from iot_manager.alerts import AlertManager, AlertType, AlertLevel

ALERTS_PATH = os.environ.get('IOT_ALERTS_PATH', '/mnt/network_storage/iot_manager/alerts.json')

monitor = ResourceMonitor(
    cpu_threshold=80.0,
    memory_threshold=85.0
)

alert_mgr = AlertManager(ALERTS_PATH)

# Check resources
results = monitor.check_resources(hostname='router')

# Create alerts if needed
for alert_info in results.get('alerts', []):
    alert_mgr.create_resource_alert(
        alert_info['resource'],
        alert_info['value'],
        alert_info['threshold'],
        'router'
    )
PYTHON_SCRIPT
```

## Troubleshooting

### Issue: Network storage not mounted

**Solution**: Check NFS/SMB mount, verify network connectivity

```bash
mount | grep iot_manager
ping server.local
```

### Issue: VLANs not creating

**Solution**: Check VLAN script permissions and em1 interface

```bash
ls -l /usr/local/sbin/update_vlans.sh
ifconfig em1
```

### Issue: Devices not detected

**Solution**: Check ARP table and DHCP leases

```bash
arp -an
cat /var/db/dnsmasq.leases
```

## Security Notes

1. **Storage Security**: Ensure network storage is properly secured with authentication
2. **Script Permissions**: Limit execution to root only
3. **Data Backup**: Regularly backup device database and alerts
4. **Alert Response**: Monitor critical alerts daily
5. **Profile Updates**: Review and update device profiles monthly

## Performance Considerations

- Detection daemon: Runs every 5 minutes (configurable)
- Resource monitoring: Runs every 15 minutes (configurable)
- VLAN updates: Runs daily at 2 AM (or on-demand)
- Firewall updates: Runs daily at 2:05 AM (or on-demand)
